Privacy Policy

App name: Supervisor UP 112 (Case Monitor - Supervisor)
Package name: upp.nextgen112.CaseMonitor
Developer: hxgnsi (INTERGRAPH SG&I INDIA PRIVATE LIMITED)
Effective date: September 30, 2026

This Privacy Policy describes how the Supervisor UP 112 mobile application for Android and iOS devices (the "App") collects, uses, shares, stores and protects information. The App is developed by INTERGRAPH SG&I INDIA PRIVATE LIMITED ("we", "us", "our") for the UP 112 emergency response service of the police department, Uttar Pradesh.

1. Who can use the App

Supervisor UP 112 is an operational tool for authorized police officers and supervisors. It is not intended for the general public. Access requires a user account issued by the police department. The App allows officers to view, filter, edit and manage emergency events, dispatch (assign) and pre-empt (unassign) units, close events, view unit and event locations on a map, listen to call recordings (for users with relevant privileges), view the incident dashboard, and manage notification settings.

2. Information we collect and why

Data typeWhat is collectedPurpose
Account and login information User ID, password and one-time password (OTP) entered during login. The user ID and password are stored on the device so the user can remain signed in, and are removed when the user logs out. Authenticating authorized users and maintaining the login session.
Device and notification identifiers Firebase Cloud Messaging (FCM) registration token, device identifier and device platform (Android/iOS). Registering the device with the UP 112 server and delivering event notifications.
Precise and approximate location The device's current location, collected only when the user uses the navigation feature on an event location map and only after the user grants location permission. Location is not collected in the background. Showing the user's position on the map and calculating a route to the event location.
Contacts A phone number that the user selects from the device's contact picker, after granting contacts permission. The App does not upload the device's contact list. Letting the user select a contact phone number within the App.
Operational (event) data Emergency event information provided by the UP 112 servers, such as event number, type, location, caller phone number, operator remarks, assigned units and unit locations, and caller call recordings. Actions taken by the user (such as updating, assigning, unassigning or closing an event) are sent to the server. Allowing authorized officers to monitor and manage emergency events.
App settings and local data Notification preference, server address setting and a list of events already viewed, stored on the device. Providing App functionality and remembering user preferences.

The App does not collect data for advertising. We do not sell, trade or otherwise transfer your data to outside parties for their own purposes.

3. Permissions used by the App

  • Internet and network state: to communicate with the UP 112 servers.
  • Location (precise and approximate): for map navigation, only while the feature is in use.
  • Contacts: to select a contact phone number.
  • Notifications: to show event notifications.

Permissions can be withdrawn at any time in the device settings. Some features may not work without them.

4. How information is shared

We do not share your data with third parties unless it is needed to operate the App or is required by law:

  • UP 112 police department servers: login, device registration and operational data are exchanged with servers operated for the police department.
  • Google Firebase Cloud Messaging: the device registration token is processed by Google to deliver push notifications. See Google's Privacy Policy.
  • Map and routing services: map tiles are loaded from OpenStreetMap. When the navigation feature is used, the user's current coordinates and the destination coordinates are sent to the OSRM routing service (router.project-osrm.org) to calculate a route. Map libraries are loaded from unpkg.com. These services may receive the device's IP address.
  • Other apps chosen by the user: when the user taps a phone number or WhatsApp action, the number is passed to the phone dialer or WhatsApp app on the device.
  • Legal requirements: where required by applicable law or a lawful request of a competent authority.

5. Data storage and retention

All data collected through the App is stored with the police department in a secure environment and is only accessible by authorized personnel. Data on the device remains until the user logs out, clears the App data or uninstalls the App. Data on the servers is retained according to the record-retention rules applicable to the police department.

6. Data protection

We are committed to protecting your data and ensuring that it is not misused. Access to the App is limited to authorized users, communication with the servers uses encrypted connections (HTTPS), and data stored with the police department is safeguarded using administrative and technical security measures. The data is used strictly for the purposes described in this policy.

7. Your choices and data deletion

Users can log out at any time to remove stored login data from the device, and can turn notifications on or off in the App's Settings menu or the device settings. User accounts are created and managed by the police department. To request access to, correction of or deletion of your account or associated data, contact your UP 112 administrator or us using the details below.

8. Children

The App is intended only for authorized adult personnel and is not directed to children.
